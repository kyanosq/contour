# Round 4 设计稿 — 「呢料与划粉」(Wool & Chalk)

先设计、后实现、再自评。本轮基线自评 8.0（上一轮 9.5 属高估：主题色气质与定位不符、
示例图为人台而非真人示范、拍摄引导缺横滚/俯仰的显性指示、动效密度不足）。

## 1. 定位与配色

定位：**高级定制（bespoke tailoring）工具**。用户是定制顾客与门店店员，气质应是
「深夜高定工作室」而非「科技仪表盘」。上一轮的青蓝 Lumen 偏医疗/科技感，与定位不符。

新色板 —— 呢料与划粉：

| 角色 | 值 | 说明 |
| --- | --- | --- |
| 页面底（曜黑） | `#070A12 → #0B1020` | 深夜藏蓝呢料，微暖 |
| 页面底（石墨） | `#161A26` | 提亮炭灰变体 |
| 主行动色 Chalk | `#E9E1CE`（曜黑下 `#F2EBDA`） | 裁缝划粉的暖白，按钮/选中态/仪器高亮 |
| onChalk | `#181C2A` | 深墨蓝，压在划粉色上 |
| 文字 | `#ECF1F8` / `#8C97AC` | 保持 |
| 成功 / 危险 | `#4FC98F` / `#F0655F` | 保持（低饱和） |

设计故事：所有「测量类」元素（卷尺针、测量带、水平环、表盘扫描、进度刻度）都是
**划粉在深色呢料上留下的痕迹** —— 一套视觉语言贯穿全部环节。环境光是一盏暖象牙色
的工作灯 + 夜窗的深蓝，不再出现青色光斑。

## 2. 示例照片（修正）

现状问题：示例图是「无头无腿的人台」，与拍摄要领（全身入镜、A 字姿态、头脚完整）
直接矛盾，用户会困惑。重新生成 2 张：**真人模特全身示范照**（贴身深色衣物，
正面 A 字姿态 / 右侧面站立，头脚完整，深色影棚 + 暖白轮廓光），与新色板同调。

## 3. 拍摄引导（面向用户，而非标注员）

原 app 的 pitch/roll 是采集给训练平台的标注元数据；Contour 中它们必须**转译成
用户看得懂的实时引导**，同时仍写入 capture_metadata 契约字段。

- **横滚（左右倾斜）**：水平环内加入**旋转地平线** —— 随 roll 实时转动的划粉线，
  归正时吸附为水平并点亮。左右两翼短线提供参照。
- **俯仰**：环内气泡只保留垂直自由度的同时，环外上下**动画箭头**（呼吸闪烁）指示
  「顶部后仰/前倾」，hint 文案随方向具体化。
- **调平吸附动效**：进入水平时环体脉冲放大一次 + 划粉发光 + 触感。
- **倒数**：数字外圈加 1 秒扫描弧，从划粉色收拢。
- **前置相机**：切换键改为「后置 ↔ 前置」显式切换（不再按索引轮转），前置时预览
  镜像修正，顶栏显示「前置」徽标；自拍场景（把手机支在桌上自测）打通。

## 4. 补缺信息 + 腰带单点标记

- 结果页头部加**被测人概要卡**：姓名 · 性别 · 身高 · 体重 · 贴合度（此前这些输入
  在结果环节完全不可见，无法核对张冠李戴）。记录详情同步补齐身高/体重/贴合度。
- **腰带位置标记（单点方案）**：正面照预览时可选拖动一条水平划粉线标记腰带高度，
  归一化 `belt_y` 写入该视图 capture_metadata。单点=只取高度、假设腰带面水平；
  相比三点方案损失腰带面的倾斜信息（前低后高的佩戴习惯），围度误差量级 1–3%
  （详见评测报告）。对消费端「自己标腰带」足够，标注级仍应三点。

## 5. 动效语言（一套系统：划粉 + 仪器）

| 环节 | 动效 |
| --- | --- |
| 全部可按元素 | 统一按压缩放 0.97 / 120ms（PressTract 包装器） |
| 首页 hero | 已有描线入场，测量带改划粉色 |
| 测量表盘 v2 | 旋转刻度环 + 划粉彗尾扫描（辉光垫层）+ 中心相位脉冲；表盘=放大的水平环，与拍摄环节同语言 |
| 成功页 | 勾章外扩涟漪环（划粉色，一次性） |
| 结果页 | 分组卡片错峰上滑入场；数字滚动保留 |
| 拍摄 | 地平线吸附、环体脉冲、俯仰箭头呼吸、倒数弧 |

## 6. 自评流程（每环节）

实现后按「登录→表单→要领→拍摄→测量→结果→保存→记录→设置」逐环节截图自审，
不合格回修；报告按 6 维标准重评，视觉维度需给出逐屏核查表。目标 ≥9.5。
